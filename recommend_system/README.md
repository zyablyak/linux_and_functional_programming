# Система рекомендаций книг

Веб-приложение для интеллектуального подбора книг по пользовательским предпочтениям.

## Основные функции

- **Умный поиск** по жанрам, авторам и ключевым словам
- **Гибкая фильтрация** по году и строгим критериям  
- **Сохранение списка** для чтения
- **Статистика библиотеки**

## Технологии

- Flask (Python) + HTML/CSS/JS
- Pymorphy3 для обработки текста
- JSON для хранения данных

## Быстрый старт

```bash
pip install flask pymorphy3
python main.py
Откройте: http://localhost:5050
